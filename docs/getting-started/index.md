# Getting Started with Creator Flows

This guide will help you get up and running with our AI-powered 3D model generation service. Whether you're a designer, developer, or 3D enthusiast, you'll be creating stunning 3D models in no time.

## What You'll Learn

In this getting started guide, you'll:

1. **Create an account** and set up your profile
2. **Take a guided tour** of the dashboard features
3. **Generate your first 3D model** from text or images
4. **Export and use** your generated models

## Prerequisites

Before you begin, make sure you have:

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A stable internet connection
- An email address for account creation
- Basic understanding of 3D concepts (helpful but not required)
