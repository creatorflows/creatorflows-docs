## File Management System

CreatorFlow provides a specialized file management system designed for media-heavy workflows.

### Uploading Files
- **Drag-and-Drop**: Easily upload assets via drag-and-drop or file browser.
- **Bulk Operations**: Select and manage multiple files simultaneously.
- **Size Limit**: Supports files up to 2GB each (configurable).

### Supported File Types
| Type | Formats |
| :--- | :--- |
| **Video** | MP4, MOV, AVI, MKV |
| **Image** | JPG, PNG, GIF, SVG |
| **Document** | PDF, DOCX, TXT |
| **Audio** | MP3, WAV |

### In-Platform Previews
Preview assets directly in the browser without downloading:
- **Video Player**: High-performance player with timeline scrubbing.
- **Image Gallery**: View images with zoom and pan.
- **Document Viewer**: Navigate multi-page PDFs.
- **Audio Waveform**: Visualize and play audio tracks.

### Version Control
Never lose track of changes with built-in versioning:
- **Auto-versioning**: Uploading a file with the same name creates a new version.
- **Revision History**: View uploader, timestamp, and optional change notes.
- **Version Restore**: Roll back to any previous version at any time.

### Organization
- **Nested Folders**: Create a logical folder structure within projects.
- **Metadata & Tags**: Add tags and descriptions to your assets for easy discovery.
- **Search**: Fast full-text search across file names and metadata.
- **File Status**: Track progress with statuses like **Draft**, **In Review**, **Approved**, and **Final**.

### Additional Features
- **Auto-Delete**: Set expiration dates for temporary assets.
- **Watermarking**: Protect your previews with custom watermarks.
